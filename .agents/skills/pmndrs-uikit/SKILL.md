# PMNDRS UIkit: 3D Spatial UI & WebGL HUD Layouts

Build responsive user interfaces that live inside the 3D scene, using familiar Flexbox layout semantics powered by Yoga engine.

## Core Capabilities
- **In-Canvas Flexbox**: `<Container>`, `<Root>`, `<Text>`, `<Image>` directly in 3D WebGL.
- **Glassmorphic 3D Panels**: Real depth, glass refraction, and spatial lighting on UI elements.
- **Spatial Interactions**: Hover, active states, and 3D pointer tracking with zero DOM overhead.
