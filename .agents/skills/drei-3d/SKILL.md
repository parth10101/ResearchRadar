# Drei: 3D Helpers & Shader Abstractions for React Three Fiber

Pre-built, battle-tested components and shaders for rapid 3D scene construction in React.

## Essential Components
- **Controls**: `<OrbitControls>`, `<CameraControls>`, `<PresentationControls>`.
- **Atmosphere & Particles**: `<Sparkles>`, `<Cloud>`, `<Stars>`, `<Sky>`.
- **Lighting & Materials**: `<Environment>`, `<MeshReflectorMaterial>`, `<Float>`.
- **Typography & HUD**: `<Text>`, `<Text3D>`, `<Html>` (projecting HTML UI directly into 3D world space).
