# Magic UI: Interactive & 3D Web Components

High-end animated and interactive components for modern web applications, dashboards, and landing pages.

## Key 3D & Interactive Patterns
- **Interactive 3D Globe**: WebGL-powered interactive globe with arc links, pulse markers, and rotation controls.
- **Animated Beam Connectors**: SVG/Canvas gradient energy beams connecting nodes in epistemic and citation graphs.
- **Particles & Network Constellations**: Interactive cursor-repelling particle clouds and physics manifolds.
- **Retro Grid & Background Beams**: Depth-inducing perspective grids and ambient glow rays.
- **Bento Grid & Number Tickers**: High-density scientometric dashboard layouts with animated counters.
